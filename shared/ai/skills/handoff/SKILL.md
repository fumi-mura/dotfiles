---
name: handoff
description: 作業状態を .agents/HANDOFF.md に書き出して、別の AI やセッションから続きを再開できるようにする
---

## 用途

Claude と Codex を行き来する場合に使う。
同じツール内で再開するだけなら `claude --resume` や `codex resume` を使う。

## 手順

1. `git status` と `git diff` で未コミットの変更を確認する
2. 今回のセッションで決めたこと、試して駄目だったことを整理する
3. `.agents/HANDOFF.md` を下記の Format で上書きする
4. 書いた内容をユーザーに提示し、目的と次の一手が合っているか確認する

## Format

```markdown
# Handoff

- 更新: {YYYY-MM-DD HH:MM}
- ブランチ: {branch}

## 目的

{何を達成しようとしているか。1〜2 行}

## 制約

- {守るべき前提。無ければ「なし」}

## 対象ファイル

- `{path}` — {何をした / これから何をする}

## 次の一手

1. {具体的な作業}

## 詰まっている点

- {未解決の問題と、試して駄目だった方法。無ければ「なし」}
```

## Guidelines

- 会話の要約ではなく、次のセッションが動き出せる情報を書く
- 「目的」と「制約」はユーザーの発言を優先する。推測で補わない
- 試して駄目だった方法を必ず残す。同じ調査を繰り返させないため
- 完了した作業は書かない。git log と diff で追える

## Constraints

- `.agents/HANDOFF.md` 以外のファイルを変更しない
- コミットや push はしない
- 認証情報やトークンを書かない
- 決定として残す価値があるものは `docs/decisions/` に分けて、ここには書かない
