# 0002: Claude の返答が英語なら Stop フックで差し戻す

- 日付: 2026-10-16
- 状態: 有効
- 対象: `shared/ai/hooks/japanese-reply.py`、`ai/claude/.claude/settings.json` の `hooks.Stop`

## 決定

返答の最後の本文がほぼ英語なら、Stop フックで止めずに差し戻し、日本語で書き直させる。コード、URL、パスは数えない。ラテン文字が40字未満の短い返答と、差し戻したあとの停止（`stop_hook_active`）は通す。

## 理由

- `shared/ai/AGENTS.md` の「常に日本語で会話する」と記憶（memory）だけでは、長いツール操作のあとの報告が英語になるのを防げなかった。Orca に変えてから頻度が上がった。
- フックなら、モデルの注意に頼らず確実に止められる。
- 指示を消したりフックを外したりすると、英語の報告に戻る。
