# 0003: AI のトークンを、指示ではなく設定とフックで節約する

- 日付: 2026-10-16

## 決定

1. Claude の自動要約は、会話が40万トークンに近づいたときに行う(`autoCompactWindow`)。
2. Bash の出力のうち会話に入れるのは8千文字までにする(`bashOutputMaxChars`)。超えた分はファイルに残る。
3. テストとビルドのコマンドは、PreToolUse フック(`quiet-commands.py`)で `quiet` 経由に書き換える。
4. Read で開く画像は、長い辺1000pxに縮めた複製に差し替える(`shrink-image.py`)。名前に `.full` を付けた画像は縮めない。
5. 前の返答から1時間以上空いて依頼したときは、`/new` を勧める一言を出す(`idle-reminder.py`)。

## 理由

- 1週間の使用量の大半は、会話の読み直し(キャッシュ読み込み)だった。毎回の返答で、それまでの会話をすべて読み直す。
- 会話に残り続けて読み直されていたのは、Bash の出力(約35%)、画像(約29%)、ツール呼び出し(約19%)。
- 指示だけでは守り忘れるため、自動で効く仕組みにした。
- 3を実行後の差し替え(PostToolUse の `updatedToolOutput`)にしないのは、失敗したコマンドの出力は差し替えられず、出力が最も長いのが失敗のときだから。
- 自動要約の40万は、1M のコンテキストで67万まで伸びていたのを抑えつつ、長い作業の途中で要約が入りすぎない値。
